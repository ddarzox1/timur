# Письмо в SIGEX перед включением production

**Тема:** Qauipsiz — уточнение сценария последовательного QR-подписания одного PDF

Здравствуйте! Мы интегрируем SIGEX для последовательного подписания одного PDF-протокола несколькими физическими лицами через eGov mobile. До подключения production просим подтвердить три пункта:

1. Можно ли на тарифе Start без mTLS зарегистрировать документ его первой подписью: выполнить `POST /api` с полем `signature`, а затем `POST /api/{id}/data` с исходным PDF?
2. Какие лимиты запросов, помимо 40 документов в месяц, действуют на Start для базового QR API, регистрации/добавления подписей и получения данных документа?
3. Можно ли вызвать `POST /api/{id}/buildDDC` без подключённого архива, передав оригинал PDF в теле запроса? Если да, какой `Content-Type` и какие настройки временного хранения обязательны?

Реальные запросы к SIGEX до получения ответов не выполняются; локально используется fake-режим.
