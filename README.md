# Qauipsiz — охрана труда (MVP)

Go + htmx + PostgreSQL. Один бинарник, шаблоны, статика и миграции встроены.

## Быстрый старт

Нужны Docker и (для запуска без Docker) Go 1.26.

```sh
make up      # создаст .env из .env.example и поднимет приложение + Postgres
```

Откройте http://localhost:8080 → «Войти»:

| Номер | Кто | Куда попадёте |
|---|---|---|
| +7 701 000 00 01 | Айгерим — админ, инженер ОТ | `/admin` |
| +7 701 000 00 02 | Ерлан — монтажник | `/m` (мобильная версия) |
| +7 701 000 00 03 | Данияр — прораб, ответственный за ЖК Алатау | `/m` |

Код входа — **1111** (тестовый режим из `.env`).

Остальные команды — `make help`:

```sh
make run         # приложение на хосте (go run) + Postgres в Docker — для разработки
make test        # все тесты, включая интеграционные
make test-unit   # быстрые тесты без базы
make lint        # gofmt + go vet
make logs        # логи контейнера
make down        # остановить
make reset       # удалить базу и загрузки (спросит подтверждение)
```

Все настройки — в [.env.example](.env.example) с комментариями. Загрузки (фото, PDF) лежат в томе `uploads`, база — в томе `pgdata`.

Вход по SMS-коду. Пока SMS-провайдер не подключён, общий код задаёт `FIXED_OTP` в `.env`; без него код случайный и пишется в лог (`make logs`). С `COOKIE_SECURE=1` (прод) сервер вместе с `FIXED_OTP` не запустится.

Сотрудник: `/m` (мобильная PWA). Инженер ОТ / админ: `/admin`.

## Архитектура

Чистая архитектура, зависимости направлены внутрь: `delivery → usecase → domain`, `repository → domain`.

```
cmd/server/main.go        точка входа: конфиг → БД и миграции → сборка зависимостей → HTTP-сервер (graceful shutdown)
internal/
  config/                 переменные окружения
  domain/                 сущности и правила без БД и HTTP (телефон, гео, подпись, доступ к опасности, сроки)
  usecase/                бизнес-логика; каждый пакет объявляет нужные ему интерфейсы (Repo, Storage, SMSSender)
    auth/ hazard/ induction/ checklist/ people/ dashboard/ pilot/
  repository/postgres/    реализация интерфейсов usecase на pgx; транзакции внутри методов; ports.go проверяет соответствие
  delivery/http/          маршруты, middleware (вход, роли, CSRF), разбор форм, рендер шаблонов, RU/KZ
  infra/sms, infra/storage  SMS (пока в лог) и хранение файлов на диске
web/                      шаблоны html/template + htmx и статика (embed)
migrations/               SQL-миграции goose (embed)
```

### Тесты

| Слой | Что проверяется | Нужна БД |
|---|---|---|
| `domain` | телефон, расстояние, подпись PNG, просрочка, видимость опасности | нет |
| `usecase/*` | бизнес-правила на фейковых репозиториях: код входа (попытки, TTL, 1111), ответственный и срок опасности, права на устранение, подпись инструктажа и гео, «Нет» в чек-листе → опасность, импорт CSV, роли | нет |
| `infra/storage` | проверка типа файла по содержимому, размер, path traversal | нет |
| `repository/postgres` | фильтры реестра, журналы по видам и датам, истекающие повторные, импорт, изоляция по организации, одноразовые коды | да |
| `delivery/http` | вход 1111 → роли, CSRF, htmx-редиректы, 400 на валидацию, изоляция организаций и файлов | да |

```sh
go test -cover ./internal/usecase/...
```

## Безопасность

- **Изоляция организаций:** каждый запрос по id фильтруется по `org_id`/`user_id` в SQL; ссылки из форм (сотрудник, объект, подразделение, шаблон) сверяются с организацией. Файлы `/files/{org}/…` отдаются только своей организации. Покрыто тестами в `repository/postgres` и `delivery/http`.
- **Роли:** сотрудник — только `/m` и свои или назначенные ему опасности; инженер ОТ — вся организация, кроме настроек; админ — всё. Админа назначает и редактирует только админ.
- **Вход:** код одноразовый, 5 попыток на код, не чаще раза в минуту и не больше 5 кодов в час на номер. Сессия — случайный токен; в БД хранится только его хеш; cookie `HttpOnly`, `SameSite=Lax`.
- **CSRF:** `SameSite=Lax` + проверка `Origin` у всех изменяющих запросов.
- **Заголовки:** CSP (`frame-ancestors 'none'`), `X-Frame-Options: DENY`, `nosniff`; загруженные файлы отдаются с `CSP: sandbox`.
- **Загрузки:** тип проверяется по содержимому, до 25 МБ на файл; тело запроса ограничено (`MaxBytesReader`). Пути к файлам задаёт только сервер, а не форма.
- **Перед продом:** задать `POSTGRES_PASSWORD`, не задавать `FIXED_OTP` и `SEED`, `COOKIE_SECURE=1` за HTTPS. Порт базы опубликован только на `127.0.0.1`.
